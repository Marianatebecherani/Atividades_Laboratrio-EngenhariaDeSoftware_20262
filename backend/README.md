# Backend

API REST do Catálogo Pessoal de Filmes e Séries: autenticação, catálogo de obras, lista do usuário, avaliações e recomendações.

## Tecnologias

- Python com FastAPI
- SQLAlchemy 2 (ORM) e Alembic (migrações)
- PostgreSQL
- uv (gerenciamento de dependências)

## Status

Em desenvolvimento. Pré-requisitos, variáveis de ambiente, comandos de execução, testes e migrações serão documentados aqui conforme forem implementados.
